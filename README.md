# Zalmaya — installateurs

Ce dépôt public ne contient que les **installateurs officiels** de Zalmaya
(Windows et macOS), publiés dans l'onglet *Releases*. Le code source de
l'application est privé.

Téléchargez Zalmaya depuis le site officiel : <https://zalmaya.com/download>.
Chaque version indique l'empreinte SHA-256 de ses fichiers.

Les versions sont construites et publiées automatiquement par l'intégration
continue du dépôt de l'application. Ce dépôt n'accepte pas de contributions.
